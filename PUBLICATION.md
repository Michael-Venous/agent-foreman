# Source publication

This repository starts with a clean, source-only snapshot. Private development history, runtime evidence, chat transcripts, account/usage records, machine inventories, databases, browser profiles and credentials are excluded. Identifiers and machine-specific examples are synthetic.

The working application and private development history are maintained separately. Do not push private development branches or merge their history here. Future updates should repeat the source-only export and secret/privacy review. A clean scan is not a guarantee that arbitrary future files are safe.
