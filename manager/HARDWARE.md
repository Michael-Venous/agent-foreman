# Local resource configuration

Maintain your machine inventory privately, outside this repository. Identify GPUs by their actual UUIDs, not unstable numeric indices. Resource keys use a machine/GPU-UUID convention; all source examples are synthetic.

Supervisor claims are advisory. Inspect actual compute use, explicit user reservations, current release evidence and pending input before handoff. A browser/compositor exception must be reviewed for that exact process; never exempt unknown compute or terminate unrelated applications. Preserve objectives and histories when retiring superseded allocation instructions.
